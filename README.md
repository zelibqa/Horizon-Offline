## About

**Horizon Offline** enables launching Horizon without signing in to a Microsoft account.

The original Horizon Launcher includes Microsoft account authentication and ownership verification requirements. This modification introduces an alternative offline launch mode, allowing users to start the game without connecting a Microsoft account.

No Microsoft account login is required to use the offline mode.

## Features

- **No Microsoft account required** — launch without Microsoft authentication.
- **Offline mode** — play without signing in to a Microsoft account.
- **Simplified startup** — skip the Microsoft account sign-in process.
- **Horizon compatibility** — based on the original Horizon Launcher.

## Requirements

- Windows (10 or higher).
- Required game resources (you need to install 26.3 minecraft files from other launcher)

## Installation

1. Download the modified launcher from the releases page.
2. Extract the downloaded archive.
3. Open Start Launcher.bat
4. Change Minecraft Files (to folder, where you installed 26.3 ORIGINAL minecraft)
5. Install required resources (button inside launcher - resources)
6. Start the game! :>

*Installation instructions may vary between releases.*

## Limitations

Offline mode does not provide Microsoft account authentication.

- Servers requiring Microsoft account authentication may not be accessible.
- Online account ownership verification is not performed by the offline login mode.
- Multiplayer availability depends on the server's authentication configuration.

**Security note:** Offline-mode servers do not verify player identities through Microsoft.
